Two modes. One app.

Switch between Travel and Trail with a single tap. Each mode has a dedicated workflow tailored to its purpose.

✈️ Travel Mode

Plan trips with AI KML.

Build multi-day travel itineraries by importing KML files generated by AI. Organize stops by day, view the full route, and navigate between stops.

  • Import AI-generated itineraries via KML
  • Add & reorder stops on the map
  • Drive time between stops
  • Export and share your itinerary as KML
🥾 Trail Mode

Log your trails.

Import GPX-style KML routes from trusted hiking sources. The original GPS LineString is preserved through export and re-import round-trips.

  • Import KML routes created in Google Earth
  • GPS route lines rendered on the map
  • FIFO-safe KML round-trip export
  • Hiking time estimation

How it works

From idea to interactive map in three steps.

1

Ask AI for KML

Ask any AI (Gemini, Claude, ChatGPT) to generate a travel KML itinerary, or use Google Earth to create trail paths.

2

Import & Edit on Map

Import your KML file into PathLog. Review and edit stops day-by-day on an interactive map.

3

Share the route

Export your finished trip as a KML file and share it — friends can import it directly into PathLog or Google Earth.
