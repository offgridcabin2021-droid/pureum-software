# OptiPay Website

A modern, responsive website for OptiPay - the Canadian tax optimization app.

## Overview

OptiPay is a sophisticated tax optimization application designed specifically for Canadian business owners. The website showcases the app's key features including:

- **Smart Tax Optimization**: Intelligent salary vs dividend calculations
- **Compound Growth**: Advanced long-term asset expansion planning  
- **Corporate Structure Analysis**: Advanced CDA, GRIP, and RDTOH management
- **Provincial Coverage**: Support for all Canadian provinces and territories
- **Professional Reports**: Detailed analysis suitable for accountants and advisors

## Website Structure

```
optipay/
├── index.html          # Main single-page website (including features and support)
├── styles.css          # Main stylesheet
├── assets/            # Images and icons
└── README.md          # This file
```

## Design Features

- **Modern Glass Morphism**: Contemporary UI with backdrop blur effects
- **Gold & Professional Theme**: Premium color scheme reflecting financial expertise
- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: Animated components and smooth transitions
- **Accessibility**: Semantic HTML and proper ARIA labels

## Key Sections (Single-Page `index.html`)

- **Hero & Banner**: Ascending winding cliff-road artwork and left-aligned headers
- **Overview & Features Detail**: In-depth breakdowns of Salary/Dividend, Compound Growth, and Corporate Accounts
- **Advisory steps & brochure**: Workflow roadmap and premium brochure preview
- **Support & FAQ**: Expandable accordion questions and direct contact resources

## Color Scheme
